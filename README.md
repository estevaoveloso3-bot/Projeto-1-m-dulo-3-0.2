# Calculadora

Projeto de uma calculadora simples desenvolvida em Python e Shell Script.

## Arquivos

- `calculadora.py` — código da calculadora em Python.
- `calculadora.sh` — versão da calculadora em Shell Script.

## Como executar o Python

No terminal, execute:

```bash
python3 calculadora.py

# chmod 744 calculadora.sh

./calculadora.sh
